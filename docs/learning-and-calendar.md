# FAQ, guides, and release calendar

Research reviewed October 12, 2026. Local implementation; not deployed.

## Research decisions

- [Pokémon Support's availability statement](https://support.pokemon.com/hc/en-us/articles/360056644571-Update-on-Pok%C3%A9mon-Trading-Card-Game-Product-Availability) describes efforts to reprint impacted products. It is not a set-by-set production register. Do not infer printing status from release age, stock listings, or tournament rotation.
- [Pokémon Center's restock policy](https://support.pokemoncenter.com/hc/en-us/articles/23363169957012-How-often-does-Pok%C3%A9mon-Center-restock-items) says support cannot provide future restock information. No exact upcoming TCG online drop window was verified for Target, Walmart, or Pokémon Center during this research. Undated records explicitly preserve that uncertainty.
- Retailer destinations: [Target Pokémon collectibles](https://www.target.com/c/pokemon-collectibles/-/N-ehy89), [Walmart new Pokémon arrivals](https://www.walmart.com/shop/trading-cards/pokemon/new-arrivals), and [Pokémon Center TCG](https://www.pokemoncenter.com/category/trading-card-game). Retailer/marketplace listings are not proof of scheduled drops, first-party inventory, or active printing. Target pages could not be fully retrieved by the research browser; the recurring Target/Walmart windows instead use the site owner’s supplied schedule and are explicitly unconfirmed.
- The [official anniversary launch announcement](https://www.pokemon.com/us/news/the-pokemon-tcg-30th-celebration-expansion-is-available-now) establishes September 16, 2026 for 30th Celebration. The [official product showcase](https://www.pokemon.com/us/news/pokemon-tcg-30th-celebration-product-showcase) gives October 30 for the Espeon ex / Umbreon ex Battle Decks, including Pokémon Center distribution. The [official Delta Reign preview](https://www.pokemon.com/us/features/heat-rotom-ex-delibird-and-more-from-pokemon-tcg-mega-evolution-delta-reign) gives November 6, 2026 for the English expansion. Some Pokémon pages returned only an iframe on direct retrieval; official indexed passages were used where available. These are release dates, not verified online checkout windows.
- Guide references include [official company history](https://corporate.pokemon.com/en-us/about/), [TCG overview](https://corporate.pokemon.co.jp/en/business/cardgame/), [product types](https://support.pokemon.com/hc/en-us/articles/360001024394-What-types-of-Trading-Card-Game-products-are-available), and [counterfeit guidance](https://support.pokemon.com/hc/en-us/articles/360002068953-Did-I-purchase-fake-or-counterfeit-cards). Website answers were checked against the repository. Questions are editorially selected common topics, not a claim about measured search frequency.

## Implementation

- `/faq`: the release calendar and set directory appear first, followed by 18 searchable questions in four categories and six original guide articles. Section links jump to Calendar, FAQ, or Guides.
- `/faq/guides/[slug]`: statically generated articles with metadata, section anchors, review dates, references, and related site tools. Unknown slugs return 404.
- `/calendar` redirects to `/faq#calendar`. The embedded calendar provides a navigable month/list calendar with date selection, retailer/type filters, separate undated drops, and retailer links. Every dated set in the shared directory data also becomes a calendar event, including historical releases. Calendar language filtering keeps English and Japanese releases separate. Date-only calculations avoid shifting set releases; today and timed retailer windows use fixed PST (UTC−8), without daylight-saving adjustments. No stock-monitoring or paid-provider requests.
- The calendar and set directory share one load of the existing `/cards/sets?game=pokemon` and `?game=pokemon-japan` routes once per mount/retry. It supports search, language, release order, printing filters, and incremental display. Missing dates stay unknown. Independent request failures retain the successful language and researched announcements, with an explicit retry message.
- The directory merges catalog sets with 187 English release records across 22 series/collections from the user-supplied [TCGplayer article](https://www.tcgplayer.com/content/article/Every-Pok%C3%A9mon-TCG-Set-in-Order-Newest-to-Oldest/02f9330b-d44a-48d3-9162-f4ce1909f0f6/) (article updated September 28, 2026; reviewed October 12), plus the Japanese anniversary announcement. Only factual names, series, and dates are stored in `frontend/lib/english-set-releases.json`; article prose and card-count tables are not reproduced. English matching handles catalog prefixes and explicit aliases, retains catalog IDs, and uses the sourced date/series. Japanese catalog dates stay separate. Unmatched catalog products remain available. The source includes international promotional dates that need not be US-exclusive launch dates; promo dates describe an initial release, not every later card.
- Expected windows: Target Tuesday/Thursday at 12:00 AM PST (start of day), Walmart Wednesday at 6:00 PM PST. These site-owner patterns are generated only for today/future days, never as historical drop claims. The estimates checkbox hides these windows and Pokémon Center reminders.
- Pokémon Center history records sourced preorder dates for Delta Reign (2026-09-30, 37 days early), Pitch Black (2026-06-10, 37), Mega Evolution (2025-07-15, 73), Destined Rivals (2025-03-24, 67), and Prismatic Evolutions (2024-11-01, 77). Each record links to its report in `pokemonCenterHistory` and appears on its historical calendar date. Article publication times are not treated as checkout times. Future English expansions receive a one-calendar-month planning reminder, clamped to month end; a matching reported preorder suppresses the reminder. No Japanese products or promo collections receive this heuristic.
- `frontend/lib/learning-content.ts` owns FAQs, guides, references, and the editorial review date. `frontend/lib/release-calendar.ts` owns date helpers, announcements, retailer destinations, and optional set-specific print evidence. No Cards/Sets schema changes or backend deployment is required.
- FAQ appears in the header; calendar shortcuts in the command palette and footer link to its calendar section. Header uses the scrollable navigation row below 1536px to fit the added destinations.

## Maintaining the data

1. Check the official announcement or retailer before adding/changing an event. Save its direct source URL and actual review date; never advance review dates automatically.
2. Classify a general launch as `release`. For `drop`, distinguish reported/announced purchase windows from explicitly labeled `expected` windows and `reminder` planning events. Never present an estimate as an announcement. A date-only record must omit `startsAt`; a timed record requires an ISO timestamp with offset. Keep unknown drops undated. Remove a retailer's undated placeholder when a confirmed upcoming drop replaces it.
3. Add researched sets only with language-specific release evidence. Do not insert made-up catalog IDs; announcement-only entries link to catalog search until ingestion catches up.
4. `printEvidence` is intentionally empty: none of the reviewed sources established a current per-set production status. To add evidence, key it by `language:catalogId`, include a set-specific source, review date, explanation, and expiry date. Expired evidence returns to Unknown. The UI supports both In print and Out of print without guessing.
5. Editorial events and evidence require manual review and a frontend rebuild/deploy. The current release list is a researched starting selection, not an automated drop feed. Catalog dates continue to come from existing catalog ingestion; this work does not enable ingestion jobs.
